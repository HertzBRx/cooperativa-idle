# Cooperativa: da carroça à central de reciclagem

Jogo de navegador (coleta com tempo + idle/incremental de gestão) sobre uma cooperativa de catadores de materiais recicláveis no Brasil.

- Tudo em um único arquivo: `index.html` (pixel art, sons e música gerados no código, sem arquivos externos).
- Abra o `index.html` em qualquer navegador moderno. Funciona com mouse e com toque no celular.
- O progresso é salvo automaticamente no navegador (localStorage).
